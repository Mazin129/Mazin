# BGP & OSPF Routing — NSE 7 Enterprise Firewall

## BGP Deep Dive

### BGP Neighbor States
```
Idle → Connect → Active → OpenSent → OpenConfirm → Established
```
| State | Description |
|-------|-------------|
| Idle | No TCP connection attempt |
| Connect | TCP SYN sent |
| Active | TCP SYN failed, retrying |
| OpenSent | TCP established, BGP OPEN sent |
| OpenConfirm | OPEN received, waiting KEEPALIVE |
| Established | Fully operational |

### BGP Message Types
| Type | Purpose |
|------|---------|
| OPEN | Initiates session (AS, router ID, hold time) |
| KEEPALIVE | Maintains session (every hold-time/3) |
| UPDATE | Announces or withdraws prefixes |
| NOTIFICATION | Signals error, terminates session |

### Route Reflector (iBGP scaling)
```bash
config router bgp
    set as 65001
    config neighbor
        edit "10.0.0.2"
            set remote-as 65001      # iBGP
            set route-reflector-client enable    # This peer is RR client
        next
        edit "10.0.0.3"
            set remote-as 65001
            set route-reflector-client enable
        next
    end
end
```

### BGP Route Manipulation

#### Route Maps
```bash
config router route-map
    edit "RM-SET-LOCAL-PREF"
        config rule
            edit 1
                set match-ip-address "Preferred-Prefix"
                set set-local-preference 200       # Prefer this path
            next
            edit 2
                set set-local-preference 100       # Default for all others
            next
        end
    next
end

config router bgp
    config neighbor
        edit "10.0.0.2"
            set route-map-in "RM-SET-LOCAL-PREF"
        next
    end
end
```

#### Prefix Lists
```bash
config router prefix-list

            edit 1
                set prefix 0.0.0.0/0

            edit 2

end
```

### BGP Conditional Advertisement
```bash
config router bgp
    config neighbor
        edit "10.0.0.2"
            set advertise-interval 5
            set advertisement-interval 5
            config conditional-advertise
                edit 1
                    set advertise-routemap "RM-ADVERTISE-BACKUP"
                    set condition-type exist
                    set condition-routemap "RM-CHECK-PRIMARY-DOWN"
                next
            end
        next
    end
end
```

## OSPF Deep Dive

### OSPF LSA Types
| LSA | Generated By | Scope | Content |
|-----|-------------|-------|---------|
| Type 1 (Router) | Every router | Area | Router's links |
| Type 2 (Network) | DR | Area | Multi-access network segment |
| Type 3 (Summary) | ABR | Area (inter-area) | Routes from other areas |
| Type 4 (ASBR Summary) | ABR | Area | Location of ASBR |
| Type 5 (External) | ASBR | Entire OSPF domain | External routes |
| Type 7 (NSSA External) | ASBR in NSSA | NSSA only | External routes in NSSA |

### DR/BDR Election
- **DR** (Designated Router): Generates Type 2 LSA; all routers form adjacency with DR
- **BDR** (Backup Designated Router): Takes over if DR fails
- Election: Highest priority → Highest Router ID
- `set priority 0` = never become DR

```bash
config router ospf
    config ospf-interface
        edit "internal"
            set priority 100        # Ensure this FGT is DR
            set dead-interval 40
            set hello-interval 10
        next
    end
end
```

### OSPF Authentication
```bash
# MD5 authentication
config router ospf
    config ospf-interface
        edit "internal"
            set authentication md5
            config md5-keys
                edit 1
                    set key-string <ospf-key>
                next
            end
        next
    end
end
```

### Route Redistribution
```bash
config router ospf
    config redistribute "connected"
        set status enable
        set metric 10
        set metric-type 2           # E2 (default); E1 = includes internal cost
    end
    config redistribute "bgp"
        set status enable
        set tag 100
    end
    config redistribute "static"
        set status enable
    end
end
```

### OSPF Summarization
```bash
# Summarize at ABR (inter-area)
config router ospf
    config summary-address
        edit 1
            set prefix 10.0.0.0/8
            set advertise enable
        next
    end
end

# Summarize external routes at ASBR
config router ospf
    config distribute-list
        edit 1
            set protocol connected
            set access-list "OSPF-Redistribute-ACL"
        next
    end
end
```

## SD-WAN

### SD-WAN Architecture
```
                    FortiGate SD-WAN
                    ┌─────────────────┐
ISP1 ──── wan1 ────┤                 ├──── LAN
ISP2 ──── wan2 ────┤  SD-WAN Zone    ├
MPLS ─── port3 ────┤                 │
                    └─────────────────┘
```

### SD-WAN Configuration
```bash
config system sdwan
    set status enable
    config members
        edit 1
            set interface "wan1"
            set gateway 203.0.113.1
            set priority 1
            set cost 10
        next
        edit 2
            set interface "wan2"
            set gateway 198.51.100.1
            set priority 2
            set cost 10
        next
    end
    config health-check
        edit "Google-DNS"
            set server "8.8.8.8"
            set interval 1000          # ms
            set failtime 3             # failures before mark down
            set recoverytime 5
            set probe-timeout 500
            set members 1 2
        next
    end
    config service
        edit 1
            set name "VoIP-Primary-ISP1"
            set mode sla
            set dst "VOIP-Servers"
            config sla
                edit 1
                    set health-check "Google-DNS"
                    set link-cost-factor latency
                    set latency-weight 10
                    set jitter-weight 5
                next
            end
            config priority-members
                edit 1
                    set member 1        # Prefer ISP1
                next
                edit 2
                    set member 2        # Failover to ISP2
                next
            end
        next
    end
end
```

### SD-WAN SLA Metrics
| Metric | Description | Good Threshold |
|--------|-------------|---------------|
| Latency | RTT in ms | < 150ms VoIP |
| Jitter | Variation in latency | < 30ms VoIP |
| Packet Loss | % lost packets | < 1% VoIP |
| MOS | Mean Opinion Score | > 3.6 VoIP |

### SD-WAN Load Balancing Algorithms
| Algorithm | Description |
|-----------|-------------|
| Source IP | Same source always uses same member |
| Weighted | Traffic split by member weight |
| Session | New sessions distributed round-robin |
| Spillover | Use secondary when primary exceeds threshold |
| SLA | Use member that meets SLA criteria |
| Maximize Bandwidth | Always use highest bandwidth member |

## Policy-Based Routing (PBR) vs SD-WAN

| Feature | PBR | SD-WAN |
|---------|-----|--------|
| Health monitoring | Manual | Built-in (latency/loss/jitter) |
| Failover | Manual backup route | Automatic SLA-based |
| Load balancing | No | Yes (multiple algorithms) |
| Application awareness | No | Yes (application steering) |
| Visibility | Basic | Rich metrics in GUI |

### When to Use PBR
- Simple forced routing for specific subnets
- When SD-WAN license is not available
- Legacy compatibility

```bash
config router policy
    edit 1
        set input-device "internal"
        set src "10.10.10.0/24"
        set dst "0.0.0.0/0"
        set action permit
        set nexthop "203.0.113.1"
        set interface "wan1"
    next
end
```
