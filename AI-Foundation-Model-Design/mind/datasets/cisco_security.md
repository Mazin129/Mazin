# Cisco Networking and Security

Cisco is a company that makes networking hardware, software, and security products used across the world.
Cisco IOS is the operating system that runs on many Cisco routers and switches.
A Cisco Catalyst switch is a widely used enterprise switch for wired local area networks.
A Cisco router forwards packets between networks and runs routing protocols such as OSPF, EIGRP, and BGP.
EIGRP is a Cisco routing protocol that shares routes efficiently within an organization.
A VLAN on a Cisco switch separates one physical switch into several logical networks.
Spanning Tree Protocol prevents loops in a switched network by blocking redundant paths.
An access control list, or ACL, on a Cisco device permits or denies traffic based on addresses and ports.
The Cisco ASA is a stateful firewall and VPN appliance for protecting networks.
Cisco Firepower, also called Firepower Threat Defense, adds next-generation firewall and intrusion prevention features.
Cisco Firepower Management Center centrally manages Firepower devices and their policies.
Cisco Identity Services Engine, or ISE, provides network access control and enforces policy on who and what connects.
Cisco AnyConnect is the Cisco VPN client that gives remote users secure access to the network.
Cisco Umbrella is a cloud security service that blocks malicious domains at the DNS layer.
Cisco Meraki is a cloud-managed networking product line configured through a web dashboard.
Cisco Duo provides multi-factor authentication to verify user identities before granting access.
Cisco Talos is the Cisco threat intelligence group that researches and tracks cyber threats.
Application Centric Infrastructure, or ACI, is Cisco's software-defined networking solution for data centers.
Cisco SD-WAN, based on Viptela, connects and manages branch sites over multiple transport links from a central controller.
A trunk port on a Cisco switch carries traffic for many VLANs between switches.
An access port on a Cisco switch belongs to a single VLAN and connects to an end device.
Cisco Secure Client is the newer name for the AnyConnect endpoint client.
