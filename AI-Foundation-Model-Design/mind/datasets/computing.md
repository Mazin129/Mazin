A computer is an electronic device that stores and processes data by following instructions.
Hardware is the physical parts of a computer that you can touch.
Software is the set of instructions and programs that tell the hardware what to do.
The CPU is the central processing unit that executes instructions and is the brain of the computer.
A CPU core is an independent processing unit, and a multi-core CPU can run several tasks at once.
RAM is random-access memory that holds data and programs the CPU is actively using.
RAM is volatile, which means it loses its contents when the power is turned off.
A hard disk drive stores data permanently on spinning magnetic platters.
A solid-state drive stores data in flash memory and is much faster than a hard disk drive.
Cache is a small, very fast memory that stores recently used data so the CPU can reach it quickly.
A GPU is a graphics processing unit that performs many calculations in parallel and accelerates graphics and AI.
A motherboard is the main circuit board that connects all the components of a computer.

An operating system is software that manages the hardware and provides services to programs.
The kernel is the core of an operating system that controls the CPU, memory, and devices.
A process is a running instance of a program.
A thread is a single sequence of execution inside a process.
Multitasking is the ability of an operating system to run many processes seemingly at once.
Virtual memory lets a computer use disk space to extend its available RAM.
A file system organizes how data is stored and retrieved on a storage device.
A driver is software that lets the operating system communicate with a hardware device.
Windows, macOS, and Linux are the three most common desktop operating systems.

Linux is a free, open-source operating system kernel used in servers, phones, and embedded devices.
The shell is a program that lets a user type commands to control the operating system.
A command-line interface lets a user control a computer by typing text commands.
The ls command lists the files in a directory on Linux.
The cd command changes the current directory on Linux.
The grep command searches text for lines that match a pattern.
A directory is a folder that contains files and other directories.
The root user is the all-powerful administrator account on a Linux system.
File permissions control who can read, write, or execute a file.
A package manager installs, updates, and removes software on a system.

The internet is a global network that connects billions of computers so they can share information.
The World Wide Web is the collection of websites and pages accessed over the internet.
A server is a computer that provides data or services to other computers called clients.
A client is a computer or program that requests data or services from a server.
Cloud computing is renting computing resources such as servers and storage over the internet.
A data center is a facility full of servers that store and process data at scale.
Virtualization lets one physical computer run many isolated virtual machines.
A container packages an application with its dependencies so it runs the same anywhere.
A database is an organized collection of data that can be searched and updated efficiently.
An API is an interface that lets one program request services from another program.
A binary number uses only the digits 0 and 1, which is how computers represent all data.
A byte is a unit of digital information made of eight bits.
A bit is the smallest unit of data and holds a single 0 or 1.
Overheating causes a computer to slow down because the CPU reduces its speed to protect itself.
Running out of RAM causes a computer to slow down because it must swap data to the slower disk.
Shutting down a computer closes all running programs and powers off the hardware.
Powering off a computer erases everything in RAM because RAM is volatile.
Data saved to a disk survives a shutdown, but unsaved work held in RAM is lost.
Rebooting a computer restarts the operating system without fully cutting the power.
Losing power suddenly can corrupt files because the computer had no time to finish writing them.
Disconnecting a computer from the network stops it from reaching the internet and other devices.
