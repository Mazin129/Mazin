# Zscaler, CrowdStrike, and endpoint security

## Zscaler

Zscaler is a cloud security company that delivers secure internet and application access as a service.
Zscaler Internet Access, or ZIA, is a secure web gateway that inspects internet traffic in the cloud to block threats.
Zscaler Private Access, or ZPA, gives users zero trust access to internal applications without a traditional VPN.
Zscaler Digital Experience, or ZDX, measures and monitors the performance users get from their applications.
Zscaler processes traffic in its own global cloud so users are protected wherever they connect.
With Zscaler, users connect to the nearest cloud node instead of backhauling traffic to a data center.

## CrowdStrike

CrowdStrike is a cybersecurity company known for its cloud-delivered endpoint protection platform called Falcon.
The CrowdStrike Falcon platform protects endpoints using a single lightweight agent called the Falcon sensor.
Endpoint detection and response, or EDR, records endpoint activity and detects, investigates, and responds to threats.
Extended detection and response, or XDR, correlates data from endpoints, network, cloud, and identity for broader threat detection.
CrowdStrike Falcon uses machine learning and behavioral analysis to detect both known and unknown attacks.
Threat intelligence is information about attackers, their tools, and their techniques that helps defenders anticipate attacks.
Managed detection and response, or MDR, is a service where experts monitor and respond to threats on a customer's behalf.
CrowdStrike Falcon Identity Protection detects and stops identity-based attacks such as stolen credentials.
An endpoint is any device that connects to a network, such as a laptop, server, or phone.

## Endpoint security concepts

Antivirus software detects and removes known malware from a device using signatures.
Next-generation antivirus uses machine learning and behavior to catch malware that signatures miss.
A security operations center, or SOC, is the team that monitors and responds to security events in an organization.
The MITRE ATT&CK framework is a public knowledge base of the tactics and techniques that attackers use.
Threat hunting is the practice of actively searching a network for hidden threats that automated tools missed.
Zero-day is a vulnerability that is exploited before the vendor has released a fix.
A false positive is an alert that flags normal activity as a threat by mistake.
