# F5 BIG-IP

F5 is a company that makes application delivery and security products, best known for the BIG-IP platform.
BIG-IP is F5's platform that load balances, secures, and optimizes the traffic to applications.
An application delivery controller, or ADC, sits in front of servers and distributes client requests across them for performance and reliability.
Local Traffic Manager, or LTM, is the F5 BIG-IP module that load balances traffic across a pool of servers.
A virtual server on a BIG-IP is the address and port that clients connect to, which F5 then forwards to real servers.
A pool on a BIG-IP is a group of backend servers that share the traffic for an application.
A pool member is a single backend server, identified by its IP address and port, inside a pool.
A node on a BIG-IP is a backend server identified by its IP address, independent of port.
A health monitor checks whether a pool member is responding, and F5 stops sending traffic to members that fail.
A load balancing method decides how F5 picks which pool member handles each request, such as round robin or least connections.
Round robin load balancing sends each new connection to the next server in turn.
Least connections load balancing sends new connections to the server with the fewest active connections.
Persistence, also called stickiness, keeps a client connected to the same server for the duration of a session.
Source address persistence keeps a client on the same server based on the client's IP address.
Cookie persistence keeps a client on the same server using a cookie that BIG-IP inserts.
SSL offloading lets BIG-IP decrypt HTTPS traffic so the backend servers do not have to, saving their resources.
An iRule is a script on BIG-IP, written in a TCL-based language, that inspects and controls traffic in custom ways.
A profile on BIG-IP is a set of settings that defines how a type of traffic, such as HTTP or TCP, is handled.
A SNAT, or secure network address translation, changes the source address of traffic so return traffic comes back through the BIG-IP.

## F5 security and DNS

Application Security Manager, or ASM, is the F5 module that provides a web application firewall to block attacks on web apps.
Advanced WAF is F5's web application firewall that protects applications from attacks such as injection, bots, and credential stuffing.
Global Traffic Manager, or GTM, now called BIG-IP DNS, load balances users across data centers using DNS.
BIG-IP DNS directs users to the best or nearest data center by answering DNS queries intelligently.
Access Policy Manager, or APM, is the F5 module that provides secure remote access, VPN, and identity-aware application access.
F5 Distributed Cloud is F5's cloud-based platform for delivering and securing applications across multiple clouds and edges.
NGINX is a web server and reverse proxy, now owned by F5, widely used for load balancing and serving web content.
A self IP on a BIG-IP is an address assigned to a VLAN that the device uses to communicate on that network.
