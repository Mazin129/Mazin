Programming is the process of writing instructions that tell a computer what to do.
A programming language is a formal language used to write software.
Source code is the human-readable text of a program.
An algorithm is a step-by-step procedure for solving a problem.
A variable is a named container that stores a value in a program.
A function is a reusable block of code that performs a specific task.
A parameter is an input value passed into a function.
A loop is a structure that repeats a block of code while a condition is true.
A conditional is a structure that runs code only when a condition is true.
An array is an ordered collection of values stored under one name.
A string is a sequence of characters, such as a word or a sentence.
An integer is a whole number without a fractional part.
A boolean is a value that is either true or false.
An object is a bundle of related data and the functions that act on it.
A class is a blueprint that defines the structure and behavior of objects.
Recursion is when a function calls itself to solve a smaller version of a problem.

A compiler translates an entire program into machine code before it runs.
An interpreter runs a program one line at a time without compiling it first.
A bug is an error in a program that makes it behave incorrectly.
Debugging is the process of finding and fixing bugs in a program.
A syntax error is a mistake that breaks the grammar rules of a programming language.
A syntax error causes a program to fail before it runs.
Testing is running a program with sample inputs to check that it behaves correctly.
A library is a collection of reusable code that programs can call.
A framework is a structured foundation that programs are built on top of.
Version control is a system that tracks changes to code over time.
Git is the most widely used version control system.
A repository is a storage location that holds a project's code and its history.

Python is a popular programming language known for being simple and readable.
JavaScript is the programming language that runs in web browsers.
HTML is the language that describes the structure of a web page.
CSS is the language that describes the style and layout of a web page.
SQL is the language used to query and manage data in a relational database.
Machine learning is a field where computers learn patterns from data instead of being explicitly programmed.
A neural network is a machine-learning model loosely inspired by the brain.
Artificial intelligence is the field of building machines that perform tasks that normally require human intelligence.
Good variable names make code easier to read and maintain.
Writing tests helps catch bugs before software is released.
