Cybersecurity is the practice of protecting systems, networks, and data from digital attacks.
The CIA triad is the model of confidentiality, integrity, and availability that guides security decisions.
Confidentiality is keeping information secret from anyone who is not authorized to see it.
Integrity is ensuring that data is accurate and has not been altered without permission.
Availability is ensuring that systems and data are accessible when authorized users need them.
Authentication is the process of verifying who a user or device claims to be.
Authorization is the process of deciding what an authenticated user is allowed to do.
Multi-factor authentication requires two or more proofs of identity, such as a password and a phone code.
Encryption is the process of scrambling data so that only someone with the key can read it.
Symmetric encryption uses the same secret key to encrypt and decrypt data.
Asymmetric encryption uses a public key to encrypt and a private key to decrypt.
Hashing is a one-way function that turns data into a fixed-length fingerprint that cannot be reversed.
A digital certificate binds a public key to an identity and is signed by a trusted authority.
TLS is the protocol that encrypts web traffic and is what makes HTTPS secure.
A VPN encrypts a user's traffic and hides it inside a tunnel across an untrusted network.

Malware is any software written to harm, exploit, or gain unauthorized access to a system.
A virus is malware that attaches to a file and spreads when that file is run.
A worm is malware that spreads across a network by itself without needing a host file.
Ransomware is malware that encrypts a victim's files and demands payment for the key.
Spyware is malware that secretly collects information about a user.
A trojan is malware disguised as legitimate software to trick a user into running it.
Phishing is a social-engineering attack that tricks people into revealing secrets through fake messages.
Social engineering is manipulating people into breaking security procedures.
A brute-force attack tries many passwords until it finds the correct one.
A denial-of-service attack floods a system with traffic so it cannot serve real users.
A man-in-the-middle attack secretly intercepts communication between two parties.
SQL injection is an attack that inserts malicious database commands through an input field.
Cross-site scripting is an attack that injects malicious scripts into a trusted website.
A zero-day is a vulnerability that is exploited before the vendor has released a fix.

A vulnerability is a weakness that an attacker can exploit to compromise a system.
An exploit is code or a technique that takes advantage of a vulnerability.
A threat is any potential cause of harm to a system.
Risk is the combination of how likely a threat is and how much damage it would cause.
Patching is applying updates that fix known vulnerabilities.
A firewall filters network traffic to block unauthorized access.
An intrusion detection system watches traffic and raises an alert when it sees an attack.
An intrusion prevention system watches traffic and blocks an attack automatically.
Antivirus software detects and removes known malware from a device.
The principle of least privilege gives each user only the access they truly need.
Defense in depth is layering multiple security controls so that one failure does not break everything.
A security policy is a set of rules that defines how an organization protects its assets.
Penetration testing is authorized simulated hacking that finds weaknesses before attackers do.
A backup is a saved copy of data that allows recovery after loss or an attack.
Two-factor authentication greatly reduces the risk of account takeover from a stolen password.
Weak passwords cause account breaches because they are easy to guess or crack.
An unpatched system causes exposure because attackers exploit its known vulnerabilities.
