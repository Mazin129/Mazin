# SASE, Netskope, Forescout, Darktrace, and NDR

## SASE and SSE

Secure Access Service Edge, or SASE, is a cloud architecture that combines networking and security into a single service delivered from the cloud.
Security Service Edge, or SSE, is the security half of SASE, bringing together secure web gateway, cloud access security broker, and zero trust access.
A secure web gateway, or SWG, inspects web traffic and blocks malicious or policy-violating sites for users anywhere.
A cloud access security broker, or CASB, gives an organization visibility and control over how its people use cloud applications.
Data loss prevention, or DLP, detects and blocks sensitive data from leaving the organization.
Zero trust network access, or ZTNA, grants users access to specific applications only after verifying identity and device posture.

## Netskope

Netskope is a cloud security company that provides a SASE and Security Service Edge platform.
Netskope inspects web and cloud traffic in its cloud so that users are protected wherever they work.
The Netskope Cloud Access Security Broker controls how employees use sanctioned and unsanctioned cloud applications.
Netskope Next Gen Secure Web Gateway filters and inspects all web traffic, not just known websites.
Netskope Private Access provides zero trust access to internal applications without a traditional VPN.
The Netskope NewEdge network is the private cloud infrastructure that Netskope uses to process traffic close to users.

## Forescout

Forescout is a company that provides network access control and device visibility across an enterprise.
Network access control, or NAC, decides which devices are allowed onto a network and what they can access.
Forescout discovers and classifies every device connected to the network, including devices without agents.
Forescout can enforce policy by quarantining or blocking a device that does not meet security requirements.
Forescout provides visibility into unmanaged and Internet of Things devices that traditional tools often miss.
Agentless visibility means Forescout identifies devices without installing software on them.

## Darktrace

Darktrace is a cybersecurity company that uses artificial intelligence to detect and respond to threats.
Darktrace builds a model of normal behavior for every user and device, then flags activity that deviates from it.
Self-learning AI means Darktrace learns what is normal for an organization on its own, without predefined rules.
Darktrace detects threats by spotting anomalies rather than by matching known attack signatures.
Darktrace Antigena, now called Autonomous Response, takes targeted action to contain a threat in real time.
The Enterprise Immune System is Darktrace's approach that treats the network like a body that learns to recognize and fight intruders.

## Network Detection and Response

Network Detection and Response, or NDR, is a security technology that monitors network traffic to detect and respond to threats.
NDR analyzes traffic patterns and behavior to find attacks that signature-based tools miss.
NDR often uses machine learning to establish a baseline of normal traffic and alert on deviations.
NDR complements endpoint detection and firewalls by focusing on what is happening across the network itself.
Lateral movement is when an attacker moves from one compromised system to others inside the network, which NDR is designed to detect.
An indicator of compromise, or IOC, is a piece of evidence, such as an IP address or file hash, that suggests a system has been breached.
A security information and event management system, or SIEM, collects and correlates logs from across the network to detect incidents.
Security orchestration, automation, and response, or SOAR, automates the steps a security team takes to investigate and contain threats.
