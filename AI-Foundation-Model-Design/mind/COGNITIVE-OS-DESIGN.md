brain that runs locally and gets smarter with use) lives one level up:

**[../07-cortex-os-cognitive-architecture.md](../07-cortex-os-cognitive-architecture.md)**

target folder structure this directory grows into.

Section 24 maps every module onto the code that already exists here and in
`../prototype/`, so it reads as an evolution path, not a rewrite.
